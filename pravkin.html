A date needs updating. A number is wrong. A page needs changing. Pravkin brings those everyday PDF tasks into a Telegram conversation.

Open Pravkin in Telegram ↗

The experience

The document
stays in the chat.

Imagine receiving a PDF with one detail to fix. You already know what needs changing. With Pravkin, you can describe it in ordinary words, right where you share the document.

The bot guides the user from upload to a reviewable result. A preview gives them a chance to check the text, numbers and layout before approving delivery of the edited file.

Built around a focused document workflow: natural-language instructions, explicit approval and file delivery in Telegram. The project is available as a limited PDF beta.

01 / UPLOAD

Start with your PDF.

Send the document directly to the bot in Telegram.

02 / DESCRIBE & REVIEW

Make the change clear.

Describe the edit in plain language, then check the proposed result and preview.

03 / APPROVE

Keep the final say.

Approve the result and receive the edited PDF back in the conversation.

Behind the experience

A focused bot
with clear checkpoints.

Python and aiogram connect the Telegram conversation to document processing. AI helps interpret the requested edits; preview and approval keep the user involved before the final file is delivered.

The workflow includes upload limits, controlled processing and short-lived file storage. Document text is sent for AI analysis only with the user's consent for that document.

Read the project case on GitHub ↗

Current scope: limited PDF beta. File limits apply, complex layouts may be unsupported, and users should check the preview before confirming. Availability is shown in the bot.
